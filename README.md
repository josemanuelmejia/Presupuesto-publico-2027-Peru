# Presupuesto-publico-2027-Peru
Base de Datos de Asignaciones Presupuestales 2027 - Perú

Construcción la base de datos de asignaciones presupuestarias propuestas por el Poder Ejecutivo en el Perú el 28 de agosto de 2026 a la Cámara de Diputados. Considerando las asignaciones presupuestarias consignadas en el citado proyecto de ley como casos, las variables que contiene son: anexo, archivo_pdf, pagina_pdf, pagina_impresa, nivel_gobierno, codigo_pliego, pliego, departamento, provincia, distrito, jurisdicciones_mencionadas, categoria_presupuestal, programa_presupuestal, producto, codigo_partida, tipo_partida, concepto, fuente_financiamiento, monto_soles, sector, alcance_territorial, base_no_duplicada, nota, cuadra_el_pliego y diferencia_del_pliego.
Se emplearon como fuentes los anexos del citado proyecto de ley, en que se consignaron las tablas que presentó el Poder Ejecutivo con los montos, concepto y pliego por asignación presupuestaria.

El procedimiento empleado para extraer y limpiar los datos es explicado en el apéndice metodológico y asistido por Claude AI.
Esta base de datos es elaborada como instrumento de política pública para identificar el punto de partida del proceso de aprobación del presupuesto público del año fiscal 2027.
